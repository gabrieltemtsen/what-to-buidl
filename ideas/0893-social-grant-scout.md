# Social Grant Scout

## One-liner
A project that turns messy docs into actionable build plans. Great for portfolio projects.

## Problem

## ICP (Ideal Customer Profile)

- One clear success metric shipped in v1

## Suggested stack

## Difficulty
intermediate

## Estimated build time
2-4 weeks

## Category
ai-agent

## Monetization angle
team collaboration seats

## What to demo (hackathon-ready)

- Include failure/edge-case handling
- Show real user value, not only model output

## Stretch goals

- Agent memory + long-running tasks
- Integrations marketplace

Build "Social Grant Scout" as a production-minded MVP with clean architecture, robust error handling, and a UX focused on one repeatable, high-impact workflow.
