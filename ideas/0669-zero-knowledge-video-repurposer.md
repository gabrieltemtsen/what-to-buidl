# Zero-knowledge Video Repurposer

## One-liner
A project that creates high-signal insights from noisy social feeds. Great for hackathon demos.

## Problem
Teams still waste time and money on fragmented tooling and manual coordination.

## ICP (Ideal Customer Profile)
onchain-native founders

## Why now
APIs are mature and builders want faster iteration.

## MVP scope
- Single high-value workflow, optimized for speed
- Human-in-the-loop approvals where needed
- Activity log + basic analytics
- One clear success metric shipped in v1

## Suggested stack
Cloudflare Workers + D1 + KV

## Difficulty
advanced

## Estimated build time
1 weekend

## Category
b2b

## Monetization angle
team collaboration seats

## What to demo (hackathon-ready)
- Complete one end-to-end user workflow without manual admin steps
- Include failure/edge-case handling
- Show real user value, not only model output

## Stretch goals
- Multi-tenant org support
- Agent memory + long-running tasks
- Integrations marketplace

## Vibe-coding prompt starter
Build "Zero-knowledge Video Repurposer" as a production-minded MVP with clean architecture, robust error handling, and a UX focused on one repeatable, high-impact workflow.
