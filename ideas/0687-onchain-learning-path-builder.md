# Onchain Learning Path Builder

## One-liner
A project that keeps communities informed with proactive summaries. Great for hackathon demos.

## Problem
Teams still waste time and money on fragmented tooling and manual coordination.

## ICP (Ideal Customer Profile)
community managers

## Why now
Cross-platform workflows are exploding in demand.

## MVP scope
- Single high-value workflow, optimized for speed
- Human-in-the-loop approvals where needed
- Activity log + basic analytics
- One clear success metric shipped in v1

## Suggested stack
Rust + Tauri + SQLite

## Difficulty
beginner

## Estimated build time
1 weekend

## Category
startup

## Monetization angle
marketplace take rate

## What to demo (hackathon-ready)
- Trigger one real-world action from a natural language command
- Include failure/edge-case handling
- Show real user value, not only model output

## Stretch goals
- Multi-tenant org support
- Agent memory + long-running tasks
- Integrations marketplace

## Vibe-coding prompt starter
Build "Onchain Learning Path Builder" as a production-minded MVP with clean architecture, robust error handling, and a UX focused on one repeatable, high-impact workflow.
