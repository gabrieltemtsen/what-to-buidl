# Agentic Hackathon Team Finder

## One-liner
A project that creates high-signal insights from noisy social feeds. Great for portfolio projects.

## Problem

## ICP (Ideal Customer Profile)

- Human-in-the-loop approvals where needed

- One clear success metric shipped in v1

## Difficulty

1 weekend

## Category
startup

- Show real user value, not only model output
