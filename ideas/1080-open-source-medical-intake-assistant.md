# Open-source Medical Intake Assistant

## One-liner
A project that creates high-signal insights from noisy social feeds. Great for weekend builds.

## Problem
Teams still waste time and money on fragmented tooling and manual coordination.

## ICP (Ideal Customer Profile)
indie hackers

## Why now
APIs are mature and builders want faster iteration.

## MVP scope
- Single high-value workflow, optimized for speed
- Human-in-the-loop approvals where needed
- Activity log + basic analytics
- One clear success metric shipped in v1

## Suggested stack
Node.js + Redis + Temporal

## Difficulty
intermediate

## Estimated build time
1-2 weeks

## Category
hackathon

## Monetization angle
SaaS subscription

## What to demo (hackathon-ready)
- Show input → AI reasoning → executable output in <90 seconds
- Include failure/edge-case handling
- Show real user value, not only model output

## Stretch goals
- Multi-tenant org support
- Agent memory + long-running tasks
- Integrations marketplace

## Vibe-coding prompt starter
Build "Open-source Medical Intake Assistant" as a production-minded MVP with clean architecture, robust error handling, and a UX focused on one repeatable, high-impact workflow.
